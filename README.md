# Builder Journal

Builder Journal is my personal portfolio and a living record of how I think, build, and grow as a software engineer.

Rather than serving as a gallery of projects, this portfolio tells the story behind the products I build—the problems they solve, the decisions that shaped them, and the lessons they taught me.

## Purpose

This project demonstrates:

- Product thinking
- Engineering decision making
- AI-assisted development
- System design
- Continuous learning
